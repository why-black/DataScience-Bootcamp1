# Module project — Data Science (School 21)

Репозиторий с учебными проектами модуля Data Science в School 21. Темы: командная строка UNIX, основы Python, ООП, управление зависимостями, эффективный код и командный анализ MovieLens. Каждый проект лежит в отдельной папке. Внутри есть код, инструкция по запуску и короткие выводы. Датасеты в репозиторий не включены, ссылки на них указаны в README нужных проектов.

## Проекты

- DSB1 UNIX Command Line Tools. Индивидуальный. curl, sort, uniq, jq, sed, cat, сбор и предобработка данных.
- DSB2 Syntax & Semantics. Индивидуальный. Синтаксис и семантика Python.
- DSB3 OOP skills. Индивидуальный. ООП в Python.
- DSB4 Package management. Индивидуальный. Библиотеки, виртуальные окружения, зависимости.
- DSB5 Efficient code practices. Индивидуальный. Оптимизация и эффективность кода.
- DSB6 MovieLens Analytics. Командный. Командная аналитика данных на MovieLens.
